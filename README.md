# CaloriePulse - Vanilla Health & Nutrition Tracker

A lightweight, responsive, and intuitive daily nutrition and calorie tracker built purely with standard HTML5, CSS3, and JavaScript. Zero external frameworks, zero build tools, and strictly literal vanilla styling with full local data persistence via the browser's `localStorage`.

## Features
- **Daily Target & Calorie Balance**: Visual SVG circular meter, linear progress bar, and real-time remaining/over-budget tracking.
- **Macronutrient Tracking**: Monitors grams and target percentages for Protein, Carbohydrates, and Fats, plus energy ratio breakdown.
- **Meal Organization**: Log foods categorized into Breakfast, Lunch, Dinner, and Snacks.
- **Quick Logging**: 1-click preset library for everyday whole foods, and instant +50/+100/+250/+500 kcal quick additions.
- **Hydration Tracker**: Interactive 250ml water glass counters with tap-to-toggle logging.
- **Date Navigation**: Jump to any day with calendar date selection or previous/next controls with per-day data persistence.
- **Daily Reflection**: Auto-saving notes section for workout notes, energy levels, or reflections.
- **Data Portability**: Full JSON export, import/restore, and reset utilities.

## Getting Started
Simply clone the repository and open `index.html` in any web browser. No server or compilation required.
